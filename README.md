# Personal Portfolio - React

A responsive personal portfolio website built using React and React Router.

This project is an extension of my previous static HTML/CSS portfolio.

## Technologies Used

- React
- JavaScript
- React Router DOM
- HTML
- CSS
- Vite

No third-party UI component libraries or state management libraries were used.
