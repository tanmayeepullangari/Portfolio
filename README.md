#Overview
This project is a responsive portfolio website made by using HTML and CSS, which will be further improved in the future ,it showcases the educational and technical details about me
#Design Idea
The design follows a presentation style layout, as each section of items in the nav bar is assigned their appropriate slide, and connected via smooth scrolling
#Layout Technique
The website uses both grid and flexbox .Grid is used for arranging the project and cards section, where as the flexbox is used for the nav bar position and hero alignment
#Limitations
Currently the portfolio is just a static version ,without using any Java script functionalities or backend
